# Order & Activity Tracker API

RESTful API sederhana yang dibangun menggunakan Java Spring Boot dengan arsitektur dual-database (SQL & NoSQL).

## 🛠️ Tech Stack
- **Backend**: Java 17, Spring Boot 3.3.0 (Spring Data JPA, Spring Data MongoDB)
- **SQL Database**: PostgreSQL (Menyimpan data Order/Transaksi)
- **NoSQL Database**: MongoDB (Menyimpan data Activity Log)
- **Containerization**: Docker & Docker Compose
